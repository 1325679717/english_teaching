## 🚀 学习流程指南
1. **输入阶段（3 分钟）**：打开当期微课讲义（如 [lesson_01.md](file:///Users/mayantao/Documents/python-playground/english_teaching/lessons/lesson_01.md)），大声朗读微对话 3 遍；
2. **内化阶段（3 分钟）**：看清骨架，搞懂“为什么这么排”，阅读 1 句变 3 句例句；
3. **输出阶段（2 分钟）**：完成文末随堂打卡题，在对话框中尝试写下 1 个属于自己的仿写句子。
